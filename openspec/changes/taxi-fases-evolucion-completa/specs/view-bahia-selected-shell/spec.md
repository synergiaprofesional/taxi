## MODIFIED Requirements

### Requirement: Shell de Bahía Adaptativo para Tablet y Desktop
El sistema SHALL adaptar el contenedor principal de la bahía seleccionada para soportar vistas divididas (*split-view*) en tablets y monitores de escritorio, manteniendo navegación táctil rápida.

#### Scenario: Detección de Dispositivo en Garita
- **WHEN** la aplicación se ejecuta en una tablet o pantalla de escritorio con ancho superior a 720 dp
- **THEN** la interfaz despliega simultáneamente la lista de turnos en cola y las tarjetas de acción operativa rápida
