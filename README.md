# 🚖 Synergia Móvil

Plataforma integral de gestión de movilidad, despacho de bahías, turnos y liquidación de pagos para flotas de transporte público y taxis.

Desarrollada por **Synergia Profesional SAS**.

---

## 📌 Visión del Proyecto

**Synergia Móvil** surge de más de 7 años de experiencia en la operación y logística del sector de taxis, consolidando una solución tecnológica **multiplataforma (Móvil y Escritorio)**, autónoma, modular y comercializable a nivel multi-empresa (SaaS / White-label).

## 💻 Características Principales

* **Doble Entorno de Operación:**
  * **App Móvil (Android/iOS):** Para despacho en campo y conductores, con soporte para impresoras térmicas portátiles **Bluetooth**.
  * **App de Escritorio (Windows .exe):** Para cabinas fijas de bahía y estaciones de control, con soporte para impresoras térmicas **USB / Red** y atajos rápidos de teclado.
* **Flujo Operativo Integrado:** Apertura y cierre de sesiones de bahía, gestión de turnos en tiempo real y recaudo de conceptos con opción de * Pagar y Enturnar* en un solo toque.
* **Arquitectura Multi-Empresa:** Preparada para operar múltiples compañías de transporte de forma independiente.
