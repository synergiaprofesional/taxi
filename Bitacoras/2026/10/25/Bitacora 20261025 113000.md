# 📝 Bitácora de Sesión — 25 de Octubre de 2026, 11:30:00

## 🎯 Objetivo de la Sesión
Diagnosticar y resolver la causa raíz por la cual los turnos en espera y despachos realizados hoy en las bahías (Garita y 29D) se visualizan correctamente en los tableros web oficiales de Odoo (`/tablero_turnos`), pero aparecían completamente vacíos en la Tablet Lenovo y el Teléfono Xiaomi. Realizar el despliegue físico y verificación en todos los dispositivos.

---

## 🔍 Diagnóstico de Causa Raíz (Iron Law de gstack)
1. **Introspección en Servidor Odoo:**
   - En `fundetaxcol.turno`, la sesión operativa diaria para hoy es:
     * Garita: ID `8843` (`fundetaxcol.sesion.bahia`)
     * 29D: ID `8842` (`fundetaxcol.sesion.bahia`)
   - La bahía física base permanente es:
     * Garita: ID `4` (`fundetaxcol.bahia`)
     * 29D: ID `2` (`fundetaxcol.bahia`)
2. **Disparidad en Serialización vs Deserialización:**
   - El endpoint móvil de Odoo (`TurnoMovil._get_data()`) retorna:
     ```python
     'bahia_sesion_id': self.bahia_id.id,  # 8843
     'bahia_id': {
         'id': self.bahia_id.bahia_id.id,   # 4
         'name': self.bahia_id.bahia_id.name
     }
     ```
   - En Flutter, `TurnoModel.fromJson` procesaba el diccionario `rawBahia` y asignaba `bahiaSesionId = 4` (la bahía base), ignorando el campo `bahia_sesion_id` (8843).
   - En `TurnoController`, `bahiaIdActual.value` contiene el ID de sesión `8843`.
   - Al filtrar turnos en cola y turnos despachados:
     `turnos.where((t) => t.enFila && t.bahiaSesionId == bahiaIdActual.value)`
     Flutter comparaba `4 == 8843` $\rightarrow$ `false` para todos los turnos del día.

## 🛠️ Implementación Realizada
1. **`lib/models/turno_model.dart`:**
   - Incorporación de campos duales `final int bahiaSesionId;` y `final int bahiaBaseId;`.
   - En `fromJson`:
     * `sesionBahiaId` extrae prioritariamente `json['bahia_sesion_id']` (8843).
     * `baseBahiaId` extrae `rawBahia['id']` (4).
     * Fallback bidireccional si alguno es 0.
2. **`lib/controllers/turno_controller.dart`:**
   - Filtrado con correspondencia dual indestructible `(t.bahiaSesionId == bahiaIdActual.value || t.bahiaBaseId == bahiaIdActual.value)` en:
     * `turnosEnCola`
     * `turnosDespachados`
     * `turnosEnColaFiltrados(query)`
     * `turnosDespachadosFiltrados(query)`
     * `totalServiciosClientes`
     * `turnoEnAtencion`
     * `enturnarVehiculo`
3. **`pubspec.yaml`:**
   - Incremento de versión a `2.1.14+16`.
4. **`ERRORES.md`:**
   - Registro permanente de **FIX-010**.
